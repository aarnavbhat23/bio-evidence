# Worked cases

These are applications of the package to public data, not nine new scientific discoveries. Inputs and reports are included so the checks can be replayed without downloading data or models. The acquisition recipe rejects source bytes that do not match the recorded snapshot.

## Reproduce

```bash
python -m pip install -e .
python -m pip install -r requirements-studies.txt
python studies/run_cases.py --cache local-data
HF_HOME=./cache python studies/run_claims.py --cache local-data --device cpu
HF_HOME=./cache python studies/run_local_lm.py --device cpu
```

GPU runs use `--device cuda` where supported. The included inference runs used CPU. Downloaded weights and raw data belong in the ignored cache directories. Several providers expose mutable current URLs; future source changes intentionally stop reacquisition. The included transformed inputs remain sufficient for offline replay of the check reports.

## Source and method notes

**MIC table.** The maintainer's [public extraction audit](https://github.com/aarnavbhat23/spear-wetlab-false-positive-audit) supplies 6,448 broader heatmap rows at a pinned commit. This broader table is not a newly expert-adjudicated assay gold set. It contains 5,048 molar-unit and 1,400 mass-unit entries. Since chemistry-specific molecular weights are absent, the mass-output guard leaves the molar records unresolved. Of the mass-unit entries, 395 are exact and 1,005 are censored. The dataset-contract case applies a deliberately unsafe modulo-five row split; its failure is an intended demonstration, not a criticism of an upstream training split. Original source/publication rights remain with their holders.

**HGNC.** The [HGNC complete set](https://www.genenames.org/download/statistics-and-files/) provides approved human genes, alias symbols and previous symbols. Matching case-folds strings and considers aliases and official symbols together. There are 2,331 keys mapping to multiple HGNC IDs in this snapshot. The first 25 sorted colliding keys are queries; all abstain by design. No contextual ground truth is manufactured, so neither selective nor overall contextual accuracy is reported. HGNC data are [CC0](https://www.genenames.org/about/license/); attribution: HGNC (RRID:SCR_002827).

**Structure.** [PDB 1L2Y](https://www.rcsb.org/structure/1L2Y), DOI [10.2210/pdb1L2Y/pdb](https://doi.org/10.2210/pdb1L2Y/pdb), contains 38 submitted NMR conformers of the 20-residue Trp-cage. The case imports MODEL records, selects C-alpha coordinates and verifies all residue maps before global rigid alignment. Median pairwise RMSD is approximately 0.658 Å. It is an experimental coordinate example, not a model-seed accuracy benchmark. Credit: Neidigh, Fesinmeyer and Andersen, *Designing a 20-residue protein*, 2002, DOI 10.1038/nsb798. PDB archive data use the wwPDB [usage policy](https://www.wwpdb.org/about/usage-policies).

**Protein embeddings.** The 100 already-public selected peptide candidates and actual ESM-2 8M embeddings are imported from the previous [neighborhood run](https://github.com/aarnavbhat23/protein-neighbor-drift/tree/main/results/esm-public-atlas), pinned to its commit. Mean top-10 overlap with amino-acid composition is 48.7%. Candidate selection and missing activity/family labels prevent a superiority claim. The quantization/resource case measures 25 warmed serial cosine-retrieval calls per saved-array roundtrip; quality is neighbor fidelity, memory is traced allocation peak and cost is zero local API spend. It does not measure ESM inference or total machine memory. Dataset/code are from the maintainer's public work; [ESM weights](https://huggingface.co/facebook/esm2_t6_8M_UR50D) retain MIT terms.

**Perturbation.** The data come from the [scGen Kang tutorial](https://github.com/theislab/scgen/blob/master/docs/tutorials/scgen_perturbation_prediction.ipynb), with 16,893 cells and source-preprocessed expression. For each of seven cell types, predict treatment-minus-control mean expression using the average delta in the other cell types. Use the first 200 alphabetical genes; no outcome-driven gene selection. There are 1,400 effect rows but only eight observed effects above the fixed 0.1 threshold. This is a simple cell-type transfer example, not donor holdout or a competitive virtual-cell benchmark. The source lacks donor annotations in this object and its preprocessing was inherited. Only aggregate effects are included here; raw cell data are reacquired separately under source terms. Cite Kang et al., 2018, and Lotfollahi et al., 2019/scGen.

**Cell Painting.** Two processed profiles from [Chandrasekaran et al.'s JUMP pilot](https://github.com/jump-cellpainting/2024_Chandrasekaran_NatureMethods_CPJUMP1) supply 520 retained treated wells. The case takes the first 128 shared alphabetical features and excludes controls/nonfinite rows. Metadata plate IDs populate the checker’s `batch` field: these are plates, not independent experimental batches. Cross-plate top-1 replicate retrieval is 24.6%, versus a random-candidate rate of 0.38%. Within-plate retrieval has zero eligible queries because each retained perturbation has one well per plate. A three-fold compound-held-out classifier identifies plate at 92.5% versus a 50% majority baseline. Plate differences may reflect real biology, timepoint, imaging or processing; these numbers alone cannot establish a technical artifact. Source profiles were already normalized together. Derived profiles retain source data terms and attribution; source hashes and selection columns are included.

**Scientific claims.** [SciFact](https://github.com/allenai/scifact), Wadden et al., *Fact or Fiction: Verifying Scientific Claims*, 2020, supplies expert claim/evidence annotations. Select the first 20 sorted development cases per label, totaling 60. For annotated cases use the first sorted evidence document; for cases without labeled evidence use the first cited abstract and `insufficient`. This is an evidence-given development diagnostic, not retrieval or hidden-test evaluation. The frozen [NLI model](https://huggingface.co/cross-encoder/nli-MiniLM2-L6-H768) is a general-domain baseline; its 512-token truncation and full-abstract input are limitations. Its mechanically chosen quote demonstrates occurrence only, not a rationale. The [SmolLM2 instruction model](https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct) generates labels/quotes on the same cases, without gold labels in prompts; invalid schema becomes abstention. Actual requests, responses and scores are retained. Pretraining overlap is unknown. Claims/annotations: CC BY 4.0; abstracts: ODC-By 1.0, per [SciFact's license](https://github.com/allenai/scifact/blob/master/LICENSE.md). Model weights retain their Apache 2.0 licenses.

None of these cases has received an independent researcher review. The results justify inspecting failure modes, not claims of clinical usefulness or model leadership.

## Small instruction-model failure

The initial SmolLM2-135M prompt produced **0 valid JSON responses out of 60**. Every response therefore became an abstention, with zero guarded coverage. This measures failure to satisfy this strict output contract; it is not a general estimate of the model's biomedical reasoning ability. The raw requests and completions are in `claim_scope/lm_raw.json`, including the long prompt and 80-token generation limit. The failed run is retained rather than replaced with invented predictions. Stronger instruction models and prompt development require a separate held-out evaluation before any performance claim.
